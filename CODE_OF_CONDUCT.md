# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its Code of Conduct. By
participating — issues, pull requests, discussions — you agree to abide by it.

Please read the full text here: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Reporting

To report unacceptable behavior, open an
[issue](https://github.com/financedistrict-platform/shopware-prism-handler/issues). All reports are
reviewed by the maintainers.
